# 导航课程学习

默认用于 `Emma-RL-ObsNav-Direct-v0` 的 `random_obstacles` 连通随机地图。
课程按任务表现升降级；不再按固定训练步数强制切换。

## 任务与噪声

同一张地图预生成三个安全任务库，每库 128 对起终点。全部端点属于同一个
膨胀自由空间连通域，地图仍来自统一随机生成分布，包含连续转弯、回环和散障绕行。

- **等级 0：基础到达。** 距离 1.5–3 m，机器人包络沿直线可通行；初始朝向相对目标
  为 ±30°，噪声倍率均匀采样于 0–0.05。
- **等级 1：绕障。** 距离 3–5.2 m，优先选择直线被障碍遮挡的点对；开阔地图允许
  直达任务，不为凑比例制造障碍。初始朝向 ±90°，噪声倍率 0.05–0.15。
- **等级 2：完整导航。** 距离 >5.2 m，任意初始朝向，噪声倍率 0.10–0.35。
- **等级 3：鲁棒性。** 与等级 2 相同的完整任务，噪声倍率提高到 0.35–1.0。

等级 1–3 中，20% 的新回合均匀抽取较低等级复习。地图不会因课程变化重建；
任务等级、噪声倍率、动力学参数和传感器调度参数都在回合重置时采样。
逐步生成的噪声样本仍然随机，但其倍率在该回合内保持固定。

噪声倍率同时作用于 LiDAR 测距噪声、扇区丢失、整帧丢失、传输延迟、采样时刻抖动、
随机采样周期偏差、动作噪声与延迟、质量/轮径/轮滑等已有域随机化参数。
倍率为零时仍按配置的标称 LiDAR 频率异步采样；不把传感器强行变成控制频率同步采样。
原有各项域随机化开关继续有效。

## 升降级规则

参数集中在 `EmmaObsNavEnvCfg.curriculum`（类型定义在 `navigation_curriculum.py`）：

- 每次进入等级后至少运行 2,000 个环境控制步；这是适应期，不是自动晋级期限。
  多环境同时 step 计一步，不乘以环境数量。
- 适应期后，每收集 512 个当前等级的已结束回合计算一次指标，窗口互不重叠。
- 连续两个窗口满足成功率 ≥80% 且失败率 ≤10%，晋升一级。
- 连续两个窗口满足成功率 ≤35% 或失败率 ≥40%，降低一级。
- 中间表现重置对应连续计数，形成迟滞，减少反复升降。

失败指碰撞、跌落或越界；超时计为未成功，进入成功率的分母。
失败与到达同时发生时，按失败统计。复习回合以及上一轮等级变化前开始的回合
不用于当前等级决策，避免简单任务抬高成功率或旧回合影响新等级。

课程不会保证在固定步数内走完：若基础能力不达标，会继续训练当前难度。
在 TensorBoard 中观察 `Curriculum/level`、`current_success_rate`、
`current_failure_rate`、`window_episodes`、`level_steps`、`noise_mean` 和
`current_episode_fraction`。成功/失败率为最近一个完整统计窗口的数据；首个窗口
完成前显示 0，应结合 `window_episodes` 判断。

## 训练、恢复与评估

原来的训练命令可直接使用，新训练从等级 0 开始。模型 checkpoint 同时保存课程等级、
适应期步数、窗口和连续计数。通过 `train.py --checkpoint ...` 恢复时自动加载；
旧 checkpoint 不含课程状态，则从配置中的 `initial_level` 开始。
若旧策略已经能完成长距离导航，可以显式设置 `curriculum.initial_level=2`。
恢复的是课程统计与模型，不是仿真中尚未结束回合的物理状态。

`play.py` 显式关闭自适应课程，默认使用等级 3 的完整距离任务，噪声倍率为 0。
加载训练 checkpoint 不覆盖评估等级。这对单环境和多环境均生效，单环境训练
也不再被误判成无噪声评估。评估仍每次启动随机地图，可用 `--seed 123` 固定随机种子。
需要扰动评估时设置 `curriculum.evaluation_noise_scale`，例如 1.0 为完整扰动。

其他世界模式以及 `structured_layout=False` 使用原有任务采样，并采用显式的
`evaluation_noise_scale`；不使用这套自适应几何课程。旧 `phase*` 配置已移除。
ring 障碍数量改由 `obs_world.num_obstacles` 指定；warehouse 改由
`warehouse_num_cylinders` 指定，默认保持原第一阶段的数量，地图初始化后固定。
